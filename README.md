# troco
Libérez la valeur de vos biens, de votre savoir et de vos actifs (véhicules, outils, logements, compétences). Une plateforme d'échange universelle sans barrières : troc direct, crédit-temps ou modèles hybrides. Échangez tout, partout, selon vos propres règles. Rejoignez la révolution du partage planétaire.
